# web/ AGENTS

前端工程（调用方控制台与管理台）的规则。根目录 `AGENTS.md` 的表达、信息与工具规范同样适用。

## 技术栈

| 层 | 选择 | 取舍 |
|---|---|---|
| 框架 / 构建 | React 19 + Vite + TypeScript | 无 SSR 需求，控制台不承担 SEO；构建产物为纯静态文件 |
| 样式 | Tailwind + 设计 Token | Token 是唯一样式来源，页面不得出现原始色值 |
| 组件 | shadcn/ui + 业务组件 | 基础件优先取组件库，缺件再自写 |
| 表格 | TanStack Table | 列定义声明式，响应式断点换呈现 |
| 数据请求 | TanStack Query | 与 URL 状态分离；不与其它请求库混用 |
| 会话态 | Zustand | 仅存会话与跨页全局态；页面状态一律进 URL |
| 路由 | React Router v7 | |
| 图标 | Lucide（`lucide-react`） | 与 shadcn/ui 同源 |

- 接口类型与客户端一律由契约文件生成，**禁止手写响应类型**。
- 不引入上述清单之外的同类库（第二套状态库、第二套请求库、第二套图标库）。

## 设计 Token

- 命名前缀 `--tmp-*`；区分参考层（`--tmp-ref-*`）与语义层（`--tmp-color-*` 等）。
- 页面与组件只消费语义层；新增业务含义先映射到既有语义，禁止造业务专属全局 Token。
- 取值用 OKLCH；主题切换走 `data-theme` 与 `.dark` 兼容类。

## 图标与品牌

- 图标一律 Lucide，**禁止 emoji，禁止用符号字符（◈ ▤ ☰ ⧉ 等）代替图标**。
- 尺寸三档：16（行内辅助）/ 20（默认与导航）/ 24（大按钮），不得随意取值。
- 图标 `stroke: currentColor`，随文字色与状态色变化，不单独写色。
- 品牌 logo 例外：保持固定品牌色与完整内部图形，不改色、不拆解；
  最小尺寸 24px；wordmark 仅用于登录页与「我的」页页脚，顶栏只放 mark。

## 页面规范

1. **屏内只允许产品文案**：数据、状态、动作、帮助提示。设计决策、实现约束、规范说明
   写进本文件，不写进页面。
2. **三态**：加载用骨架屏（列表视图用表格骨架，卡片视图用卡片骨架，不得串用）；
   空态用统一空态组件并给出下一步动作；错误态按错误码分支（401 回登录并带 `redirect`、
   402 给充值指引、429 显示 `Retry-After` 推算的等待时间、5xx 显示错误页与手动重试按钮，
   **不自动循环重试**）。
3. **数据展示**：金额与用量是 decimal 字符串，**禁止经 `Number` / `parseFloat` 参与计算**
   或格式化，展示层做补零与千分位；数字列 `tabular-nums` 对齐。时间输入为 RFC3339，
   显示按本地化格式。状态一律「颜色 + 文字/图标」成对，不靠颜色单独表达。
4. **表格**：筛选、搜索、分页、tab 全部写入 URL query，刷新与分享保持状态；
   分页用偏移（契约信封的 `page` / `size` / `total`），列表数据在 `data.items`，
   不自行造分页形态。
5. **表单**：提交即校验，错误定位到字段；破坏性操作经确认组件；
   密钥明文只在创建响应展示一次，列表永远只显示前缀。
6. **会话**：受保护页未登录跳转登录页并携带 `?redirect=`，回跳地址只允许站内相对路径
   且排除登录页自身；令牌不得明文写入 `localStorage`。

## 移动端

- 断点沿用 Tailwind 默认值，禁止页面内散落自定义断点；触控目标 ≥ 44px。
- 导航为底部 Tab，数量 ≤ 5；Tab 承载任务域，不承载数据实体。
- 商家上下文切换位于「我的」页（Bottom Sheet 唤起），顶栏只读显示当前商家；
  单商家时不显示上下文行。
- 模型、日志等实体走全屏列表页（搜索 + 分段控件 + 长列表虚拟滚动），不占 Tab；
  首页仅提供横滑预览入口。
- 表格在窄屏改为「主字段卡片行」：断点隐藏次要列由列定义声明，不在页面里写分支。
- 二级页顶栏为返回箭头 + 页面标题，不放 logo。
- 375px 宽度下核心页面可用；设备差异只允许出现在 query 参数与客户端行为上，
  不得出现在接口路径与响应结构上。

## 多角色

- 导航与首页段落由清单数据按角色渲染，**组件不分叉、不按角色复制页面**。
- 角色与权限的真相在服务端，前端不得硬编码角色字符串；无权访问统一回 403 页面。
- 字段级隔离由服务端白名单保证，前端隐藏只是体验，不是安全边界。

## 工程与门禁

- 依赖与工具链版本只在仓库根 `.mise.toml` 声明。
- 前端检查走独立目标（lint / test），**不得并入 `make check`**——根门禁只依赖
  Go 与 golangci-lint。
- 测试分层：纯逻辑与 hooks 用单元测试，关键流程（登录回跳、深层链接、权限路径）
  用端到端测试。
- 错误处理、`context` 传递、资源释放与根目录约定同源；HTTP 响应体必须关闭。

## 文档与引用

- 代码、注释与提交只陈述客观事实：不写「建议」「可以」，不写对话式指代。
- 引用源只允许已提交文件；决策追溯用 issue 编号（`#NN`），不引用仓库外的文档编号。
- 功能先落地，再更新文档；不写计划、进度与待办进仓库文档。

## 本地 UI 示例

- UI 示例（页面草稿、方向对比稿）只在本地查看，由根目录 `.gitignore` 的
  `web/prototypes/` 排除，不入库、不作为引用源、不提交到分支。
- 示例确定为最终实现后，其结论写进本文件的对应条目，页面代码重新进入版本库。
